My SCST1133 Learning Journey

Connecting all nine course themes—from foundational architectures and data acquisition to governance, ethics, and emerging technologies.

Stage 01 • Building the Base

Foundations, Tools & The Data Landscape

1. Foundations of Data Engineering

Understanding how data engineers differ from data scientists—focusing on reliable infrastructure, schemas, and system availability before modeling begins.

2. Tools & Ecosystem

Connecting Python (pandas), SQL databases, cloud notebooks (Google Colab), and BI tools (Looker Studio) into a cohesive workflow.

3. The Data Landscape

Distinguishing structured relational tables, semi-structured JSON/CSV logs, and unstructured media across OLTP and OLAP environments.

Stage 02 • Moving & Shaping Data

Lifecycle, Acquisition & Industry Reality

4. Data Engineering Lifecycle

Tracing data end-to-end: Generation → Ingestion → Storage → Transformation → Serving, backed by security and DataOps.

5. Data Acquisition

Practicing ethical dataset sourcing, schema validation, handling missing values, and designing user-centered collection interfaces in Figma.

6. Industry Perspectives

Insights from industry talks and visits showing how Malaysian enterprises manage legacy migration, scalability bottlenecks, and cross-team collaboration.

Stage 03 • Responsibility & The Future

Governance, Ethics & Emerging Areas

7. Data Governance

Ensuring data lineage, metadata documentation, access control, and single-source-of-truth standards so downstream analytics remain trustworthy.

8. Ethics & Privacy

Applying PDPA principles, anonymization, and bias auditing so automated pipelines never expose private identifiers or reinforce unfair outcomes.

9. Emerging Areas

Exploring real-time streaming pipelines, cloud data lakehouses, and AI-ready vector workflows shaping modern data engineering.
